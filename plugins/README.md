# plugins/

这个文件夹放配套的 **DSH Tavern 插件**。插件本身不改控制器，只是让角色卡的正文
能驱动控制器：读 `osr` / `osr-compose` 代码块、按关键词触发、把播放进度交给卡片面板。

> **⚠️ 18+**：插件用于成人角色扮演场景，未满 18 岁请勿使用。

## 目录

```text
plugins/
└─ dsh-osr-device/
   ├─ index.mjs        # 插件本体（ESM，宿主侧运行）
   ├─ package.json     # name / version / license 等元信息
   └─ README.md        # 插件自己的详细说明（触发方式、设置项、协议示例）
```

## 安装

1. 先把控制器跑起来（仓库根目录的 `启动控制器（后台常驻）.bat`），
   确认 <http://127.0.0.1:8899> 能打开；
2. 把 `dsh-osr-device` 整个文件夹复制到 Tavern 插件目录：

   ```text
   ~/.dsh/profile-data/tavern/data/plugins/dsh-osr-device/
   ```

3. **重启 DSH**（宿主侧 `index.mjs` 的首次加载与任何修改都需要重启）；
4. 打开 Tavern → 设置 → DSH Tavern → 插件，确认状态是「已加载」。

## 进游戏后

本局设置里打开 **允许模型自主决定动作**，否则正文里的组指令不会执行
（`{"stop":true}` 始终有效）。

## 插件做了什么

| 能力 | 说明 |
|---|---|
| 提示词注入 | 把动作组名、动作库英文名、指令格式写进提示词（每轮一次） |
| 指令识别 | `osr` 代码块（单组 / 连播 / 停止）、`osr-compose`（模型自己拼一段） |
| 多组触发 | 一轮里出现多个 `osr` 块时一次发出，控制器先播第一个、其余进轮换池 |
| 进度回传 | `dsh-osr-device/state` 返回 `sequence:{group,index,total,left}`、`pending`、`estop` |
| AI 暂存 | 编排块里带 `"save":"组名"` 时送到控制器「AI 暂存」，等玩家确认 |
| 掉线容错 | 控制器没开或设备没连时静默跳过，正文照常，不抛错、不卡顿 |

## 注意

- 插件只访问 `127.0.0.1:8899`，不发起任何外部请求；
- 控制器是独立进程，重启 DSH 或关掉浏览器页面都不会中断设备；
- 不支持浏览器脚本卡（只走宿主侧插件）。
