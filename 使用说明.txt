============================================================
OSR2 / SR6 中文控制器 v4 —— 使用说明
====================================

【v4 更新（重要）】
  1. 急停：右下角红色圆形按钮「急停」，或者随时按 Esc 键 → 立即 DSTOP（连发三次）。
     后台还有一层保险：如果界面 10 秒没有任何操作（关掉页面/断网），会自动停机。
  2. 预设可以在卡片上直接改：名称、轴、形状、行程下限/上限、频率、时长，
     改完自动保存，不用再弹窗。
  3. 速度自动匹配：程序按「行程 × 频率」算出需要的速度，避免幅度被削平；
     若超出设备上限（9999 单位/秒），会**自动降低实际频率**并在卡片上提示
     “需 XXXX，超出上限 → 自动降到 X.XX Hz”，保证动作幅度完整。

【2026-10-28 修复（为什么以前双击没反应）】
  · 所有启动 bat 原来都靠 %PY% 变量调用 Python，但没有任何文件给它赋值，
    于是 "%PY%" server.py 展开成空路径 → 双击闪退 / 后台版静默失败 → 页面打不开。
    现在新增 「_find_python.bat」自动查找 Python（本目录 Python310 → PATH → py 启动器
    → 常见安装位置），找不到会明确提示，不再假装启动。
  · 后台常驻版原来写不出 server.log（pythonw 没有控制台，print 全被丢弃），
    所以起不来时没有任何证据。现在经 「_bg_run.py」 把输出接进 server.log（UTF-8，记事本可看）；
    启动失败时脚本会把 server.log 最后几行直接显示出来。

【页面打不开？先看这里】
    控制器是由一个后台进程提供的网页服务。**关掉那个黑窗口 = 服务停止，页面就打不开了。**
    所以推荐用「启动控制器（后台常驻）.bat」——它没有黑窗口，不会误关。
    页面打不开时按顺序检查：
      1. 双击「检查运行状态.bat」：显示“运行中”就是服务好的，直接开 http://127.0.0.1:8899
      2. 显示“没有运行中”→ 双击「启动控制器（后台常驻）.bat」
      3. 还是不行 → 看同目录 server.log 最后几行（UTF-8），把内容发我


【怎么启动（三选一）】
    * 启动控制器（后台常驻）.bat   ← 推荐：无窗口，已在跑就直接开页面
    * 启动控制器.bat               带黑窗口，能看实时日志，适合排错
    * 启动控制器（手机可访问）.bat  绑 0.0.0.0，手机同 WiFi 可访问
    停止：双击「停止控制器.bat」（会先发 DSTOP 再退出）


【它是什么】
    参考 Ayva Stroker Lite 做的本地中文控制器，不联网：
      1) 手动控制：L0 / R1 / R2 / R0 四轴 + 速度 + 安全上下限
      2) 预设：分组（慢速/中速/快速/主题），每组 10 个可自定义，支持整套切换 + 整套连播
      3) Funscript：拖入即播，波形、倍速、循环、点击定位
      4) 视频同步：拖入视频，脚本跟着视频时间走
      5) 手机/平板：同 WiFi 浏览器控制


【连接设备】
    启动后顶部一般已自动连上 TCode 桥（127.0.0.1:7777）；没连上就点「连接」：
      - 自动：先试串口 COM3，失败再试桥
      - 只用串口：需要没有别的程序占用 COM3（打开串口会让 Arduino 复位一次，正常）
      - 只用 TCode 桥：复用 Chatbox 的守护进程
    标题旁出现绿点 = 已连接。


【预设分组】
    * 顶部胶囊：慢速 / 中速 / 快速 / 主题，点一下整套切换
    * ＋新建组 / 复制当前组 / 重命名 / 删除组
    * ▶▶ 整套连播：按顺序把 10 个预设跑完，结束回中位停下
    * 卡片右上角 ✎ 修改：名称、轴、形状、行程、频率、时长、速度
    * 存在 presets.json；删掉即恢复默认


【Funscript / 视频】
    * 拖 .funscript 到虚线框，自动按文件名分轴（surge→R1、sway→R2、twist/roll/pitch→R0，其余 L0）
    * ▶ 播放 / ⏸ 暂停 / ✕ 清空、循环、0.5x~2x 倍速、点波形跳转
    * 拖入视频并勾选「与脚本同步」：播放/暂停/拖动/倍速/结束 全部跟随


【手机控制】
    双击「启动控制器（手机可访问）.bat」，窗口里会显示 http://192.168.x.x:8899
    手机连同一 WiFi 打开即可；第一次要允许 Windows 防火墙。
    ⚠ 同一网络内谁都能控制设备，只在可信 WiFi 使用。


【安全】
    * 安全上下限（默认 15%~85%）、速度上限（默认 5000）
    * 「全部停止」= 立即 DSTOP
    * 预设/连播/脚本结束 → 回中位 + DSTOP
    * 停止脚本/关窗口 → 先 DSTOP 再断开
