🧪 测试版 V0.1

  • 这是测试版，功能还在变动，可能有 bug 或行为变化。 请先小幅度、短时间测试，确认你的设备运行正常、动作组没有顶到行程，再正式游玩。 第一次用建议不超过 30% 幅度、单段不超过 10 秒。
  • 本项目配合 DSH Tavern 使用（插件装在 Tavern 里）： github.com/flizzywine/dsh-tavern
  • 控制器本体不依赖 Tavern：不开 Tavern 也能单独当播放器用。 只有要"文字驱动设备"时才需要装插件。
  • 遇到问题先看「八、出问题了看这里」，再看 server.log。

⚠ 先看这三条

  1. 手边随时能按到急停。红色「急停」按钮按下后会锁存——所有运动指令被拒， 直到点「归中 恢复」或按 Esc 走解锁流程。
  2. 无人看管时不要运行。要长时间连续播，用「联动 → 播完 → 循环本组」并设一个 「最长 N 分钟」，别让它整晚跑。
  3. 先用小幅度试。新动作、新组、新设备，先把幅度滑到 30–40% 试一次， 确认行程没顶死、线材没被拽住，再加大。

一、第一次启动

  • 启动控制器（后台常驻）.bat —— 浏览器会自动打开 http://127.0.0.1:8899，窗口不占屏幕。
  • 启动控制器.bat —— 只想临时用一次，关掉黑色窗口就停止。
  • 启动控制器（手机可访问）.bat —— 手机连同一个 WiFi，按窗口里显示的 http://192.168.x.x:8899 打开。
  • 控制器是独立进程：关掉浏览器页面不影响它，重启 DSH 也不影响它。 要停就双击 停止控制器.bat。

二、连接设备

  • 顶部「后端」选 自动（WiFi → 串口 → 桥），填设备 IP，点「连接」。
  • 连不上时依次试：确认设备与电脑在同一 WiFi → 改用串口（选 COM 口）→ 用 TCode 桥（127.0.0.1:7777）。
  • Windows 防火墙要允许 Python 访问网络；server.log 里有失败原因。
  • 右上「运行状态」看：后端、模式、预设、四轴位置。没连上时页面照常可用， 只是设备不动。

三、动作库

  • 内置 42 个动作，总数上限 80（到顶会拒绝新建）。
  • ▶ 播放一次；✎ 改曲线（内置也能改，改的是「覆盖层」）；↺ 还原； ✕ 删除自建动作（内置不能删）。
  • 「幅度」是每个动作各自的输出比例；「速度」和「时长」在播放前调。
  • 「新建动作」里可以先试听（不保存），满意再存；有「被 N 个动作组使用」提示， 改这条曲线会一起影响那些组。

四、联动：动作组、触发、循环

  • ① 关键词 → 动作组：绑一个关键词，正文里出现就播；组名本身也算触发词。
  • ② 动作组编辑：两个标签页——「我的动作组」和「AI 暂存」。 加入动作时可填 BPM / 幅度% / 时长秒；组能新建、复制、重命名、删除。
  • 打断方式（顶部条下拉）：正在播 A 时又来了 B—— 播完当前动作再切（默认）/ 整组播完再切 / 立刻切。
  • 播完（顶部条下拉）：停止 / 循环本组 / 循环并换组。 选循环后，一轮对话结束、没人碰界面也会继续播，直到「最长 N 分钟」自动停。 （没开循环时，界面 10 秒没有任何请求会被看门狗自动停，这是防关页面的安全机制。）
  • AI 编排：勾「启用」后，模型可以自己拼一段组合只播一次、不写入动作库。 这里的触发标记、段数上限、单段最长、BPM 上限都改完即时生效。
  • AI 暂存：模型经你同意存下的组先落在这里（不直接进你的动作组）。 点「保存为我的动作组」才转正，之后就能用关键词或代码块触发。

五、脚本·视频

  • 把 .funscript 拖进虚线框即可播放，可循环、调倍速。
  • 勾「与脚本同步」后，播放视频会自动开始脚本。

六、校准

  • 按设备选轴映射：OSR2 一般用 L0 / R1 / R2；四轴都动说明固件支持多轴，属正常。
  • 行程范围（默认只允许 25%–75%）与速度上限在这里改。软件限制不能替代你的判断， 真正的机械极限取决于你的整机与摆件。

七、接 DSH Tavern（让文字驱动设备）

  • 插件 dsh-osr-device 放进 ~/.dsh/profile-data/tavern/data/plugins/，重启 DSH，在设置里确认「已加载」。
  • 进游戏后本局设置里打开 允许模型自主决定动作，否则组指令不执行（stop 除外）。
  • 正文里可以写：
```osr
{"group":"前戏·慢"}
```
  • 一轮里写多个块 = 连播（先播第一个，其余进轮换池）。
  • 模型自己组合一段（只播一次、不落盘）：
```osr-compose
{"compose":[{"stroke":"down-forward","bpm":40,"secs":20}],
 "gain":0.7,"label":"慢起快收"}
```
  • 控制器没开时插件会静默跳过，正文照常，不报错。

八、出问题了看这里

  • 点连接失败：同 WiFi？串口？防火墙？看 server.log。
  • 连上但不动：是否按过急停（锁存）→ 看「运行状态」→ 幅度是不是 0。
  • 关了页面还在动：正常，控制器是独立进程。按 Esc 或双击 停止控制器.bat。
  • 页面卡：关掉 3D 预览（右侧「启用」勾选框）。
  • 改了动作没生效：Ctrl+F5 强刷。
  • 内置动作被改坏了：点卡片上的 ↺ 还原。
  • AI 编排没反应：确认「AI 编排」里勾了启用；动作名必须是动作库里的英文名。
  • 组名不存在：组名必须是「联动」里真实存在的，一个字都不能编。

九、身体上的注意事项

  • 疼痛、麻木、头晕、心悸 → 立刻急停并停止使用。
  • 有心血管疾病、癫痫、皮肤损伤、近期手术等情况，先咨询医生。
  • 不要在床上、枕边等无法立即脱身的位置使用；不要在有其他人在场、 无法中断的场合使用。
  • 长时间连续使用要设「最长 N 分钟」，不要整晚运行。
