# examples/ 联调示例

这两个脚本是开发时用的**接口联调示例**，直接用 Python 标准库，不需要 `pip install`。
它们会**真的让设备动**，请先把手放在急停上、并把幅度调低再看输出。

## 先决条件

1. 控制器已经在运行（`启动控制器（后台常驻）.bat`），地址是 `http://127.0.0.1:8899`；
2. 设备已连上（或者你已经知道连不上会怎样——脚本会在 `connect` 那一步打印原因）；
3. 设备处于安全位置，行程内没有障碍。

## 用法

```bash
python examples/test_api.py     # 连接 → 小位移 → 加载 funscript → 播放 → 停止
python examples/test_v2.py      # 动作组：新建 / 切换 / 逐条播放 / 整套连播 / 删除
```

两个脚本都会打印每一步的接口返回，方便对照。

## 需要你改的地方

脚本里连的是 `{"prefer": "bridge", "port": "COM3"}`：

- 用串口就改成你自己的端口（控制器顶部下拉里能看到的那个，例如 `COM3`）；
- 用 WiFi 就把 `prefer` 改成 `"wifi"`，并确保 `config.json` 里的 `device_host` 是设备 IP。

## 注意

- `test_api.py` 会**临时生成一段正弦 funscript**（不写盘），并在 6 秒后停止；
- `test_v2.py` 会创建一个叫「测试组」的动作组，跑完会把它删掉；
- 两个脚本都会调用 `/api/stop` 收尾。如果中途 Ctrl+C，请手动点界面上的「全部停止」。
